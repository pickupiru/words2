Swedish Word Trainer Cloud — setup

This version stores your lists in Supabase so the same account can use them from your PC, phone, tablet, or another computer.

1. Create a Supabase project

Create a project at supabase.com. In the project dashboard, find the Project URL and Publishable key (Settings → API Keys, or the Connect dialog).

2. Create the database table and security rules

Open SQL Editor in Supabase, paste the complete contents of setup.sql, and run it. The Row Level Security policies make each user's lists private.

3. Configure the app

Edit config.js in a text editor and replace the two placeholders:

window.SWT_CONFIG = {
  supabaseUrl: "https://xxxxx.supabase.co",
  supabasePublishableKey: "sb_publishable_xxxxx"
};

Do not use a service_role key.

4. Host the folder

Upload index.html and config.js to a static web host such as GitHub Pages, Netlify, or Cloudflare Pages. HTTPS is recommended and is normally provided automatically.

5. Configure Supabase Auth URLs

In Supabase Authentication URL settings, set Site URL to your hosted app address, for example:

https://yourname.github.io/swedish-word-trainer/

Add the same URL to the allowed redirect URLs if needed. The app uses passwordless email magic links.

6. Use it

Open your hosted page, enter your email, and request a sign-in link. Use the same email on your phone or any other computer and the same cloud lists will appear.

Importing lists from version 2

If you open the cloud version in the same browser that contains your older local lists, press Import lists from old local version. It reads the old swt-lists browser storage and uploads those lists to your account.

What stays local?

The vocabulary lists are cloud-synced. UI preferences such as speech speed, delay, randomize, and repeat remain device-local, which is usually convenient because different devices can have different voices and playback preferences.
